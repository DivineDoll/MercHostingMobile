# MercHosting Mobile

Aplicación independiente para crear, ejecutar y administrar
servidores Minecraft Java directamente desde Android.

## Funciones previstas
- Paper y Vanilla
- Fabric, Quilt, Forge y NeoForge
- Modrinth y CurseForge
- Administración de archivos
- Consola en tiempo real
- Gestión de jugadores
- Descargas automáticas
